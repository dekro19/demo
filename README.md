Regex-детектив
Учебный проект по регулярным выражениям на Python.
1. Запуск и правила
Для запуска игры:
py -3.14 -X utf8 main.py
Для запуска отдельных глав:
py -3.14 -X utf8 main.py —chapter passes
py -3.14 -X utf8 main.py —chapter report
Для запуска автоматических тестов:
py -3.14 -X utf8 -m unittest discover -v
На приглашение regex> необходимо вводить регулярное выражение без кавычек и ограничивающих слешей.
Команда :hint показывает подсказку, :quit завершает игру.
2. Описание проекта
Игра состоит из двух глав:
• След у проходной — проверка пропусков через re.fullmatch и поиск номеров через re.finditer.
• Архивный журнал — маскирование кодов через re.sub и разделение текста через re.split.
3. Структура проекта
• main.py — управление игрой, попытками, уликами и переходами.
• rounds.py — интерфейс и проверка регулярных выражений.
• passes.py — первая глава.
• report.py — вторая глава.
• tests/ — автоматические тесты проекта.
